# GPT tespit ve çözüm raporu — v18.7.4 RC1

Tarih: 02.10.2026. Taban: `fbbe2d7d` / `v18.7.3-rc1-gpt-audit`. Çalışma dalı: `v18.7.4-rc1-mac-discovery`.

Bu güncelleme kullanıcının üç MAC ekran görüntüsü, `stalker_v24.md` referansı, kaynak kod ve bağlı OnePlus 7 Pro DEV logları üzerinden hazırlandı. Referans Python çalıştırılmadı; paket kurulmadı ve referansın port taraması uygulanmadı. Gerçek sunucular üzerinde toplu harici tarama yapılmadı. Aşağıdaki testler üretim kodunu kontrollü HTTP/native sınırlarında çalıştırır; cihazda gerçek sağlayıcı hesabının erişimi ayrıca gözlenmelidir.

## Referans MD değerlendirmesi

2070 satırın tamamı okundu. Normalleştirilmiş soft404 karşılaştırması, pasif aynı-origin API ipuçları ve istek sonuçlarını ihtiyatlı yorumlama fikirleri yararlı. Ancak marka içeren catch-all HTML skorunun soft404'te korunması, baseline'dan önce erken duruş, farklı port linklerinin orijinal porta taşınması, CDN=koruma varsayımı, TLS kapatma ve sınırsız gövde okuma aktarılmadı. Referans hesap handshake/profile/erişim doğrulaması yapmıyor.

Resmi [Infomir Ministra REST API açıklaması](https://wiki.infomir.eu/eng/ministra-tv-platform/ministra-setup-guide/rest-api-v1) hesap durumu ve tariff_expired_date anlamlarını destekler; bu yönetim REST API'si MAG istemci protokolünün tüm klon varyasyonlarını garanti etmez. HTTP200 ile başarılı hesap kimliği/erişim farklı kanıtlardır.

[React Native ağ belgesi](https://reactnative.dev/docs/network#known-issues-with-fetch-and-cookie-based-authentication) global fetch'in manuel redirect ve cookie omission sınırlamalarını açıklar. [Expo SDK 54 fetch belgesi](https://docs.expo.dev/versions/v54.0.0/sdk/expo/#expofetch-api) mobil streaming transportunu belgeler. Kurulu `expo/android/.../fetch/NativeRequest.kt` kaynak kodunda credentials INCLUDE değilse `CookieJar.NO_COOKIES`, redirect FOLLOW değilse `followRedirects(false)` ve `followSslRedirects(false)` uygulanması ayrıca doğrulandı. Yeni paket eklenmedi.

## Dosya bazında uygulama

- `frontend/src/utils/magPortalDiscovery.ts`: MAC'siz raw HTTP/proxy keşif, same-origin/kurulum yolu, bounded body/redirect/timeout, portal/API kanıtı ve aday sonuçları.
- `frontend/src/utils/magBulkScan.ts`: keşif önce, seçili endpoint sonra; negatif host sonucu bütün MAC'ler için yeniden kullanılabilir; manuel seçim/cancel; gerçek hesap validator.
- `frontend/src/utils/magBulk.ts`: HTTPS web portlarında doğru şema, kullanıcı açık port/şema önceliği.
- `frontend/app/mag-bulk.tsx`: iki aşama, bounded portal listesi, manuel/auto seçim, unverified kart, tekrar doğrulanmadan playlist shell oluşturmayı reddetme, bozuk TXT tarihi.
- `frontend/src/utils/stalker.ts`: token/profil/ret/MAC/endpoint/örnek erişim doğrulaması; bounded scoped req; normal profile-unsupported catalogue fallback korunur.
- `frontend/src/utils/accountExpiry.ts`: uygulama genelinde aynı deterministik tarih sözleşmesi.
- `frontend/modules/panel-scan/index.ts`, `PanelScanModule.kt`, `ScanProxyPool.kt`: yeni opt-in bounded-cancellable proxy isteği; eski katalog API'si varsayılanları korunur.
- `frontend/src/player/PlayerHost.tsx`, `timeshiftPauseOwnership.ts`, `timeshiftMode.ts`, `frontend/app/(tabs)/settings.tsx`: pause ve ayar yükleme sahipliği, geç native sonuç temizliği, PREPARE kanıtı; tek upstream kuralı korunur.
- `frontend/src/store/PlaylistContext.tsx`: kuyrukta bekleyen `addPlaylist` işleminin profil sahibi girişte yakalanır; yeni profilin deposuna yazılamaz.
- Yeni runtime kapıları: `test-mag-portal-discovery.js`, `test-mag-account-validation.js`, `test-timeshift-onpause-ownership.js`. Mevcut bulk/proxy regresyonları genişletildi.
- Eski Stalker VM kapıları `_account-expiry-runtime.js` ile gerçek parser'ı yükler; parser taklidi veya assertion kaldırma yok. v18.7.0/v18.7.2 kapıları yeni keşif orkestrasyonunu denetler; `denetle.js` yeni kapıları çalıştırır.
- `app.json` ve `package.json`: beş sürüm alanı18.7.4 /180704 /RC1; yeni bağımlılık veya lockfile değişimi yok.

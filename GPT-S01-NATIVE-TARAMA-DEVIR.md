## Gerçek test komutları ve kapsamı

`node tools/test-panel-scan-runtime.js` gerçek JS parser fixture'larını ve native çağrı entegrasyon sözleşmesini çalıştırır. Ana `denetle.js` buna bağlandı. Bu flagsiz koşu Kotlin runtime çalıştırmış gibi sunulmaz.

`node tools/test-panel-scan-runtime.js --native` gerçekten cached Kotlin compiler ile production helper ve service'den alınan fonksiyon gövdelerini derleyip JVM'de çalıştırır. Android UI/ContentResolver/Keystore sınırları fixture olarak sağlanır; worker, producer, parser, snapshot, probe, finalize gövdeleri kaynaktan alınır. Gerçek SQLite UPDATE ve gerçek yerel 127.0.0.1 HTTP yanıtları kullanılır. Hiçbir gerçek panel/abonelik endpoint'ine istek yapılmaz. Native koşu JDK, cached Kotlin/org.json JAR'ları ve `node:sqlite` destekleyen Node ister; yeni paket kurulmaz.

Son `checkpointVersion=2` değişikliği bütün yeni job payload'larına uygulandıktan sonra `node tools/test-panel-scan-runtime.js --native` tekrar çalıştırıldı ve EXIT 0 verdi. Gerçek son footer: `PASS: panel scan offline runtime regressions`. Legacy replay/versiyonlu resume, gerçek SQL checkpoint sıfırlaması, HTTP cache/cooldown, üç modda worker failure/cancel, 500 hesaplık streaming ve recovery testleri geçti. Dört eski koruma denetleyicisi de ayrı EXIT 0 ile çalıştırıldı: `check-v17008-conservative-checkpoint.js`, `check-v17007-scan-journal-resume.js`, `check-v1720-streaming-scan-pipeline.js`, `check-v1711-discovery-hardening.js`. `git diff --check` temizdir.

SQLite testleri, journal kaynağındaki gerçek checkpoint/reset UPDATE ifadelerini çalıştırır. Android SQLite cursor/şifreleme katmanının tamamı JVM fixture'da çalıştırılmaz; eski yanlış sonuçları ayıklayan keyset sorgusunun Android üzerindeki yürütülmesi, tam derleme ve cihaz kabulünün kapsamındadır. Fixture'daki journal sınırı, kurtarma sayacının bu ayıklama sonrasındaki davranışını doğrular.

Android release Kotlin derlemesi, APK üretimi ve gerçek cihazdaki tarama/pause/cancel/process-kill/recovery smoke testi ana sürüm doğrulamasının parçasıdır; JVM/SQLite fixture geçişi bu cihaz davranışlarını tek başına kanıtlamaz. Final build sonucunu ana devir belgesi kaydetmelidir.

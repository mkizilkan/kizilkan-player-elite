# v17.3.0 RC1 — uygulama ve doğrulama durumu

Taban: v17.2.2 RC1, GitHub commit 0cd7ba2d493198cc070255a4d634a36cc7fa33b0.

Uygulananlar:
- Liste ve içerik türü seçerek temizleme / manuel güncelleme; liste başına ayrı transaction ve silme doğrulaması. Hesap/favori/izleme verileri korunur; otomatik VACUUM yoktur.
- Room sayaçlarına dayalı ekran yenileme; temizlenen türlerin otomatik geri dolmasını engelleyen metadata.
- Yerel görünüm sonrasında varsayılan 15 dakika aralıklı arka plan kontrolü, tür bazlı fingerprint karşılaştırması, eksik tür onarımı, profil/liste sahipliği kontrolü. Delta API olmayan kaynaklarda katalog indirmesi gerekir.
- Splayer + MasterIPTV bağımsız önbellek ve hata yönetimi; gerçek kod / kodsuz panel ayrımı; kaynak kökeni ve ham DNS saklama.
- Kaynak ve hedef filtreleri, çoklu panel seçimi; aynı kimlik bilgileri + canonical DNS için fiziksel deneme paylaşımı ve panel sonuçlarının ayrı korunması. Native dedup günlüğü şifreli ve kalıcıdır.
- Seçili tür yenileme ve ilk indirme için gerçek durum kartları; arka plan kontrolü küçük durum metni kullanır.

- TypeScript --noEmit: geçti.

- Yeni işlev testleri: DNS normalizasyonu, kaynak izolasyonu/tek kaynak kesintisi, ortak DNS probe paylaşımı, scoped Xtream/M3U yenileme, başarısız yenilemede patch üretmeme, cooldown ve liste kilidi.
- pin.ts, profile-select.tsx ve MPV/player dosyaları tabanla aynı.
